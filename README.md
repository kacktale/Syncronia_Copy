# 🎵 Syncronia : Rhythm Game Scripts

Unity 기반 리듬 게임 프로젝트 **Syncronia**에서 제가 직접 개발한 주요 시스템의 코드를 정리한 레포지토리입니다.

채보 에디터의 초기 기능부터 인게임 노트 생성 및 판정 시스템까지, 리듬 게임의 핵심 플레이 흐름을 구현했습니다.

---

## 프로젝트 요약

**담당 직무** | 리듬 게임 시스템 프로그래머
**주요 담당** | 채보 에디터, 노트 데이터 관리, 인게임 노트 스폰, 판정 시스템
**개발 환경** | Unity, C#, JSON

---

# 🎼 개발 내용

## 1. Editor Snap System

### 채보 에디터 스냅 기능

채보 에디터에서 마우스로 노트를 배치할 때 노트가 정해진 비트 간격에 맞춰 배치되도록 스냅 기능을 구현했습니다.

BPM과 그리드 간격을 기준으로 사용자의 입력 위치를 가장 가까운 채보 위치로 보정하여, 노트가 불규칙한 위치에 설치되는 문제를 방지했습니다.

이를 통해 일정한 박자 단위로 채보를 제작할 수 있으며, 수동 배치 과정에서 발생하는 위치 오차를 줄였습니다.

---

## 2. Note Duplicate Validation

### 노트 중복 설치 검사

동일한 레인과 동일한 시간 위치에 여러 개의 노트가 중복으로 설치되지 않도록 검사하는 기능을 구현했습니다.

노트를 생성하기 전에 해당 위치에 이미 노트가 존재하는지 확인하고, 중복된 위치에서는 새로운 노트가 설치되지 않도록 처리했습니다.

이를 통해 잘못된 채보 데이터가 생성되는 것을 방지하고, 인게임에서 여러 노트가 겹쳐 생성되는 문제를 사전에 차단했습니다.

---

## 3. Note Placement & Deletion

### 노트 설치 및 삭제 시스템

채보 에디터에서 마우스 입력을 이용해 노트를 설치하고 삭제할 수 있는 기본 편집 기능을 구현했습니다.

사용자가 선택한 레인과 스냅 위치를 기준으로 노트를 생성하며, 기존에 배치된 노트를 선택하면 삭제할 수 있도록 구성했습니다.

노트 설치 과정에서는 스냅 처리와 중복 검사를 함께 수행하여 유효한 위치에만 노트가 생성되도록 설계했습니다.

```text
마우스 입력
    ↓
레인 및 시간 위치 계산
    ↓
스냅 위치 보정
    ↓
중복 노트 검사
    ↓
노트 설치 또는 삭제
```

---

## 4. Note Sorting & Save System

### 노트 정렬 및 채보 저장

에디터에서 제작한 노트 데이터를 인게임에서 사용할 수 있도록 정렬하고 JSON 형식으로 저장하는 기능을 구현했습니다.

사용자가 노트를 설치한 순서와 관계없이, 저장 시 노트의 시간 정보를 기준으로 데이터를 정렬하도록 구성했습니다.

이를 통해 인게임 노트 생성 시스템이 채보 데이터를 처음부터 순차적으로 읽고 처리할 수 있도록 했습니다.

저장되는 데이터에는 다음과 같은 정보가 포함됩니다.

* 노트가 등장하는 시간
* 노트가 배치된 레인
* 노트의 종류
* 채보 진행에 필요한 노트 데이터

```text
에디터 노트 데이터 수집
        ↓
노트 시간 기준 정렬
        ↓
저장용 데이터로 변환
        ↓
JSON 직렬화
        ↓
채보 파일 저장
```

---

## 5. In-Game Note Spawn System

### 인게임 노트 생성 시스템

저장된 채보 데이터를 불러와 기록된 시간과 레인에 맞춰 인게임 노트를 생성하는 시스템을 구현했습니다.

채보에 저장된 노트 데이터를 순차적으로 확인하고, 음악 진행 시간에 맞춰 필요한 노트를 지정된 레인에 배치합니다.

에디터에서 제작한 채보 데이터가 실제 게임 플레이로 연결될 수 있도록 채보 저장 구조와 인게임 생성 구조를 연동했습니다.

```text
JSON 채보 불러오기
        ↓
노트 데이터 순차 확인
        ↓
생성 시간 비교
        ↓
지정된 레인에 노트 생성
        ↓
판정선을 향해 이동
```

---

## 6. Rhythm Judgment System

### 리듬 게임 판정 시스템

플레이어가 키를 입력하면 해당 레인에서 판정 대상이 되는 노트를 탐색하고, 노트와 판정선 사이의 거리를 기준으로 판정을 계산하는 시스템을 구현했습니다.

입력 시점과 노트 도착 시점의 차이에 따라 여러 단계의 판정을 반환하도록 구성했습니다.

```text
Marvless
Perfect
Good
Near
Bad
Miss
```

판정 결과에 따라 콤보와 플레이 데이터가 갱신되며, 판정 범위를 벗어난 노트는 Miss로 처리됩니다.

또한 한 레인에 여러 노트가 존재할 경우 플레이어와 가장 가까운 노트를 우선적으로 판정하도록 하여, 잘못된 노트가 입력 대상으로 선택되는 문제를 방지했습니다.

```text
플레이어 키 입력
        ↓
입력한 레인의 노트 탐색
        ↓
판정선과 가장 가까운 노트 선택
        ↓
노트와 판정선의 거리 계산
        ↓
판정 결과 반환
        ↓
콤보 및 플레이 데이터 갱신
```
